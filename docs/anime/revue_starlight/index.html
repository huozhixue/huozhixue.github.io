少女☆歌剧 Revue Starlight，又名：少女☆歌劇 レヴュースタァライト、Shoujo Kageki Revue Starlight、Revue Starlight

简介

“舞台少女”——以未来的舞台女演员为目标，光芒四溢的少女们。 某天，她们收到了一封邮件。“请去取得吧你所希望的那颗星”为了摘取闪耀的星星，而聚集于选拔会场的9名舞台少女。

追求光芒的心意、执着、命运——在舞台上交错。 现在，正是拉开Revue的序幕之时。
