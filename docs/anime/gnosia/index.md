# 古诺希亚


> <u>**[古诺希亚](https://bgm.tv/subject/526448)**</u>，又名：グノーシア、宇宙人狼、GNOSIA

## 简介

故事发生在一艘漂流的太空船上。由于一种“会伪装成人类来袭击人类的未知敌人”——「古诺希亚」混入船内，互相猜疑的乘员们决定每天投票选出一名可疑人物，让其进入冷冻睡眠。

如果能让所有古诺希亚全部进入冷冻睡眠则人类获胜。反之，若无法找出古诺希亚，乘员们就会遭到袭击。主人公尤里必须要做出正确的选择，与此同时，他发现自己陷入了一个时间循环中，无论做出怎样的选择，都会回到第一天。

乘员们究竟能否做出正确的选择？时间循环背后隐藏的秘密是什么？随着故事发展，乘员们不为人知的真面目也逐渐浮出水面。

在短暂的时间里不断重复，一瞬却仿佛永恒的故事，如今拉开帷幕。

——那么，祝您旅途愉快。
