# 弹丸论破 希望学园与绝望高中生


> <u>**[弹丸论破 希望学园与绝望高中生](https://bgm.tv/subject/56093)**</u>，又名：ダンガンロンパ 希望の学園と絶望の高校生 THE ANIMATION、弹丸论破：希望的学园和绝望高中生、枪弹辩驳、Danganronpa: Kibou no Gakuen to Zetsubou no Koukousei The Animation

## 简介

故事以「私立希望之峰学园」作为舞台，该学校的入学要求有两个：1.必须是现役高中生。2.必须在其独特的领域具有超一流的水平。由政府公认办学，可以说能够从这间学校毕业的话人生几乎是等同于成功了。而主人公苗木诚和有着各式各样不同风格与擅长领域的14名超高校级学生一起参加入学典礼的时候，却看到一个自称是学园长的活动布偶熊表示：「一旦进来，就必须要一辈子都待在这里才行。如果想要毕业离开的话，只要互相残杀就好了！」就这样，因为这个不合理的理由，这群被关在这个绝望学园的高材生们，陷入除了杀人之外就是被杀的阴谋当中，加上破坏学生之间信赖关系的卑劣「学级裁判」制度，更让整个真相陷入扑朔迷离当中……
