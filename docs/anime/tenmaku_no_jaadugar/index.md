# 穹庐下的魔女


> <u>**[穹庐下的魔女](https://bgm.tv/subject/552533)**</u>，又名：天幕のジャードゥーガル、穹廬下的魔女、Tenmaku no Jaadugar、Jaadugar: A Witch in Mongolia

## 简介

13世纪，一名少女身处伊朗的奴隶市场。

这是一个将辽阔大陆操弄于股掌间的一位魔女的故事。失去母亲，又被迫远离故乡的希塔拉，年纪尚幼，既没有独自生存的能力，也没有未来的希望。这样的她，被心地善良的学者一家的夫人法蒂玛收留。

「只要透过学习变聪明，不管遇到什么困扰，都会知道怎么做才是最好的」法蒂玛的儿子穆罕默德的一番话触动了希塔拉。她明白了「知」的可能性与重要性，开始充实自己的学识。她梦想着有朝一日能追上踏上求知之旅的穆罕默德。

就在此时，由皇帝成吉思汗所统治，地表最强的「蒙古帝国」正不断向他国发动侵略，势力与日俱增。那永无止境的野心，终于也波及了希塔拉居住的城市。在帝国第四皇子拖雷的侵略下，安稳的日子画上了句点。

失去一切的希塔拉，发誓要向这个深不可测的强国复仇。
